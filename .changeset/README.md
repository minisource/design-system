# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`.

## Usage

When you make changes to any package, run:
```
pnpm changeset
```

Follow the prompts to describe your changes. This will create a markdown file in `.changeset/` that describes the changes.

To version packages:
```
pnpm changeset version
```

To publish packages:
```
pnpm changeset publish
```
